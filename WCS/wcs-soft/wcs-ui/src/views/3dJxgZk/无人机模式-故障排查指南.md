# 🚁 无人机模式 - 故障排查指南

## ✅ 问题已修复

### 修复内容

**原问题**：鼠标移动无法控制无人机

**原因分析**：
- 鼠标事件在构造函数时就绑定了
- 但是`onMouseMove`中检查`enabled`状态
- 只有调用`enable()`后`enabled`才为`true`
- 导致事件虽然触发但立即返回，无任何效果

**解决方案**：
1. ✅ 将鼠标事件绑定移到`enable()`方法中
2. ✅ 在`disable()`方法中移除鼠标事件
3. ✅ 移除`onMouseMove`中的`enabled`检查（因为只有启用时才绑定）
4. ✅ 添加调试日志确认绑定/移除

## 🐛 常见问题及解决方案

### 问题1：鼠标移动没有反应

**检查项**：
- ✅ 是否已点击「无人机飞行」按钮？
- ✅ 鼠标是否在3D画面区域内？
- ✅ 控制台是否显示「鼠标事件已绑定」？

**解决方案**：
```javascript
// 强制重新绑定事件
this.firstPersonController.disable()
this.firstPersonController.enable()
```

### 问题2：准星没有显示

**检查项**：
- ✅ `isFirstPersonMode` 是否为 `true`？
- ✅ 浏览器是否支持CSS backdrop-filter？

**解决方案**：

### 问题3：HUD显示NaN或undefined

- ✅ `firstPersonController` 是否已创建？

**解决方案**：

### 问题4：视角旋转太快或太慢

**解决方案**：

### 问题5：无人机不自动前进

**检查**：

**症状**：
- 鼠标右键还能旋转场景
- 控制不稳定

**解决方案**：

## 📝 关键修复点

### 修复前后对比

**修复前**：
```javascript
// 构造函数中绑定事件
bindEvents() {
  this.domElement.addEventListener('mousemove', this.onMouseMove);
}

// onMouseMove中检查enabled
onMouseMove(event) {
  if (!this.enabled) return;  // ❌ 导致事件无效
  // ...
}
```

**修复后**：
```javascript
// 构造函数中不绑定鼠标事件
bindEvents() {
  // 只绑定键盘事件
}

// enable()时绑定鼠标事件
enable() {
  this.enabled = true;
  this.domElement.addEventListener('mousemove', this.onMouseMove); // ✅
}

// disable()时移除鼠标事件
disable() {
  this.enabled = false;
  this.domElement.removeEventListener('mousemove', this.onMouseMove); // ✅
}

// onMouseMove不检查enabled（因为只有启用时才绑定）
onMouseMove(event) {
  // 直接执行逻辑 ✅
}
```
