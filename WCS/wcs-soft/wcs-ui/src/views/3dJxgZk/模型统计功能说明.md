# GLB模型统计功能使用说明

## 功能概述

该功能用于统计GLB 3D模型的详细信息，包括面数、顶点数、网格对象数量等。

## 使用方法

### 方法1：自动统计（推荐）

模型加载完成后会**自动**在浏览器控制台输出统计信息。

1. 打开页面
2. 等待模型加载完成
3. 按 `F12` 打开浏览器开发者工具
4. 切换到 `Console`（控制台）标签页
5. 查看统计输出

### 方法2：手动触发

点击页面右上角**调试控制面板**中的「查看模型统计」按钮

### 方法3：控制台手动调用

在浏览器控制台中执行：
```javascript
// 假设你的Vue组件实例可以访问
this.getModelStatistics()
```

### 字段说明

| 字段 | 说明 |
|------|------|
| **总面数（三角形）** | 整个模型包含的三角形总数，是衡量模型复杂度的重要指标 |
| **总顶点数** | 整个模型包含的顶点总数 |
| **网格对象数量** | Mesh类型对象的数量 |
| **总对象数量** | 场景中所有对象（包括Group、Light等）的数量 |
| **name** | 对象名称 |
| **triangles** | 该对象的三角形数量 |
| **vertices** | 该对象的顶点数量 |
| **hasIndex** | 是否使用索引缓冲区（优化标志） |

## 性能参考

### 面数与性能关系

| 总面数范围 | 性能等级 | 说明 |
|-----------|---------|------|
| < 50,000 | 优秀 ⭐⭐⭐⭐⭐ | 在所有设备上流畅运行 |
| 50,000 - 100,000 | 良好 ⭐⭐⭐⭐ | 在大多数设备上流畅运行 |
| 100,000 - 200,000 | 中等 ⭐⭐⭐ | 中高端设备可流畅运行 |
| 200,000 - 500,000 | 较低 ⭐⭐ | 仅高端设备可流畅运行 |
| > 500,000 | 差 ⭐ | 需要优化模型 |

### 优化建议

如果模型面数过高，可以考虑：

1. **模型简化**
   - 使用Blender等工具减少面数
   - 移除不可见的面
   - 合并相邻的平面

2. **LOD（细节层次）**
   - 根据距离显示不同精度的模型
   - 远处物体使用低面数模型

3. **实例化渲染**
   - 对重复的对象使用InstancedMesh
   - 减少DrawCall

4. **剔除优化**
   - 启用视锥剔除
   - 启用遮挡剔除

## 技术细节

### 三角形计算方式

```javascript
// 使用索引缓冲区的模型
triangles = geometry.index.count / 3

// 不使用索引缓冲区的模型
triangles = geometry.attributes.position.count / 3
```

### 为什么是三角形？

- 3D渲染引擎最终都会将所有几何体转换为三角形
- 三角形是最简单的多边形，保证平面性
- GPU硬件优化针对三角形进行

## 常见问题

### Q1: 为什么只显示前20个对象？
**A:** 为了避免控制台输出过多信息，默认只显示面数最多的前20个对象。可以修改代码中的 `.slice(0, 20)` 来调整数量。

### Q2: 为什么有些对象没有显示？
**A:** 默认只显示面数超过100的对象，可以修改代码中的 `if (triangles > 100)` 条件。

### Q3: 如何导出统计数据？
**A:** 函数会返回统计对象，可以这样使用：
```javascript
const stats = this.getModelStatistics();
console.log(JSON.stringify(stats, null, 2));
```

### Q4: hasIndex字段是什么意思？
**A:** 
- `true`：使用索引缓冲区，内存效率高（推荐）
- `false`：不使用索引缓冲区，顶点可能重复

## 扩展功能

### 统计特定对象

```javascript
// 只统计RGV相关对象
this.ThreeEngine.scene.traverse((obj) => {
  if (obj.isMesh && obj.name.includes('rgv')) {
    const triangles = obj.geometry.index 
      ? obj.geometry.index.count / 3 
      : obj.geometry.attributes.position.count / 3;
    console.log(`${obj.name}: ${Math.round(triangles)} 个三角形`);
  }
});
```

### 实时监控

```javascript
// 每5秒输出一次统计信息
setInterval(() => {
  this.getModelStatistics();
}, 5000);
```
