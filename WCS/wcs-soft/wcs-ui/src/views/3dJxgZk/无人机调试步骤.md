## 🐛 问题排查清单

### 检查项1：控制台是否有「鼠标事件已绑定」？

**❌ 没有** → 说明enable()没有被调用或执行失败
```javascript
// 手动调用
this.firstPersonController.enable()
```

**✅ 有** → 继续检查项2

---

### 检查项2：移动鼠标时控制台是否有鼠标位置日志？

**❌ 没有** → 说明鼠标事件没有触发
```javascript
// 测试DOM元素是否能接收鼠标事件
const dom = document.getElementById('3d')
dom.addEventListener('mousemove', (e) => {
  console.log('✅ DOM可以接收鼠标事件:', e.clientX, e.clientY)
})

// 如果这个有输出，说明DOM正常，问题在事件绑定
// 如果这个也没有输出，说明DOM有问题
```

**✅ 有** → 继续检查项3

---

### 检查项3：目标旋转值是否在变化？

**❌ 一直是0或不变** → 说明计算逻辑有问题
```javascript
// 手动设置并观察
this.firstPersonController.targetRotationX = 0.5
this.firstPersonController.targetRotationY = 0.5
// 观察相机是否旋转
```

**✅ 有变化** → 继续检查项4

---

### 检查项4：是否看到Update日志？

**❌ 没有** → 说明update没有被调用
```javascript
// 检查isFirstPersonMode
console.log('模式状态:', this.isFirstPersonMode)  // 应该是true

// 如果是false，重新进入模式
this.toggleFirstPersonMode()
```

**✅ 有** → 继续检查项5

---

### 检查项5：相机是否真的在旋转？

```javascript
// 持续监控相机旋转
setInterval(() => {
  console.log('相机旋转:', 
    'X:', this.ThreeEngine.camera.rotation.x.toFixed(3),
    'Y:', this.ThreeEngine.camera.rotation.y.toFixed(3),
    'Z:', this.ThreeEngine.camera.rotation.z.toFixed(3)
```

## 🆘 紧急处理方案

### 方案A：使用Canvas元素

如果容器div不行，尝试使用canvas：

```javascript
// 在控制台执行
this.firstPersonController.disable()
this.firstPersonController.domElement = this.ThreeEngine.renderer.domElement
this.firstPersonController.enable()
console.log('✅ 已切换到canvas元素')
```

### 方案B：强制重新初始化

```javascript
// 完全重新创建控制器
const dom = document.getElementById('3d')
this.firstPersonController = new FirstPersonController(
  this.ThreeEngine.camera,
  this.ThreeEngine.scene,
  dom
)
this.isFirstPersonMode = false
this.toggleFirstPersonMode()
console.log('✅ 已重新创建控制器')
```

### 方案C：使用window监听

```javascript
// 如果div监听不行，尝试window
this.firstPersonController.disable()

// 修改onMouseMove绑定到window
window.droneMouseHandler = this.firstPersonController.onMouseMove.bind(this.firstPersonController)
window.addEventListener('mousemove', window.droneMouseHandler)

this.firstPersonController.enabled = true
console.log('✅ 已绑定到window')
```

## 📊 诊断参考值

### 正常工作的参考值

```
鼠标在画面中心附近:
  mouseX: -0.1 ~ 0.1
  mouseY: -0.1 ~ 0.1
  
鼠标在画面左侧:
  mouseX: -1.0 ~ -0.5
  
鼠标在画面右侧:
  mouseX: 0.5 ~ 1.0
  
目标旋转（灵敏度0.3时）:
  targetRotationX: -0.3 ~ 0.3
  targetRotationY: -0.3 ~ 0.3
```

### 异常情况

```
❌ mouseX, mouseY 一直是 0
   → 鼠标事件没有触发

❌ targetRotation 一直是 0
   → 鼠标位置计算有问题

❌ currentRotation 一直是 0
   → update没有被调用

❌ 相机rotation不变化
   → 欧拉角应用有问题
```
