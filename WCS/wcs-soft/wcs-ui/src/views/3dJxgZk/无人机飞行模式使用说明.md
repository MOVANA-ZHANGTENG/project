# 🚁 无人机飞行模式使用说明

## 功能概述

无人机飞行模式让您像操控无人机一样在3D场景中自由飞行，通过鼠标位置控制飞行方向和角度，无需点击或锁定鼠标。

## 🎮 核心特性

### 1. 鼠标位置控制
- **无需点击** - 直接移动鼠标即可控制
- **实时响应** - 鼠标位置直接映射飞行角度
- **平滑过渡** - 自动插值实现流畅飞行

### 2. 自动前进
- 默认启用自动前进
- 像真实无人机一样持续飞行
- 可通过控制台切换开关

### 3. 直观的控制方式
- 鼠标左移 → 向左转
- 鼠标右移 → 向右转
- 鼠标上移 → 抬头上升
- 鼠标下移 → 低头下降

## 🚀 快速开始

### 第一步：进入无人机模式

点击右上角调试控制面板的「**🚁 无人机飞行**」按钮

### 第二步：开始飞行

1. **移动鼠标**到画面上（无需点击）
2. 鼠标会自动控制飞行方向
3. 无人机自动向前飞行

### 第三步：退出模式

点击「**退出无人机模式**」按钮返回轨道控制

## 🎯 操作方法

### 鼠标控制（主要控制方式）

| 鼠标位置 | 飞行效果 | 说明 |
|---------|---------|------|
| **画面中心** | 保持直飞 | 鼠标在中心时平稳飞行 |
| **左侧区域** | 向左转弯 | 越靠左转弯越急 |
| **右侧区域** | 向右转弯 | 越靠右转弯越急 |
| **上方区域** | 抬头上升 | 越靠上抬头越多 |
| **下方区域** | 低头下降 | 越靠下低头越多 |
| **左上角** | 左转+上升 | 组合控制 |
| **右下角** | 右转+下降 | 组合控制 |

### 键盘辅助控制

| 按键 | 功能 | 说明 |
|------|------|------|
| **W** 或 **↑** | 加速前进 | 与自动前进叠加 |
| **S** 或 **↓** | 减速/后退 | 与自动前进相反 |
| **A** 或 **←** | 横向左移 | 侧向平移 |
| **D** 或 **→** | 横向右移 | 侧向平移 |
| **Space** | 快速上升 | 垂直上升 |
| **Shift** | 快速下降 | 垂直下降 |

## 💡 飞行技巧

### 1. 平稳飞行
- 保持鼠标在画面**中心区域**
- 小幅度移动鼠标进行微调
- 避免大幅度快速移动

### 2. 急转弯
- 将鼠标移到画面**边缘**
- 配合 A/D 键横向移动
- 实现快速转向

### 3. 爬升和俯冲
- **鼠标上移** + **Space键** = 快速爬升
- **鼠标下移** + **Shift键** = 快速俯冲

### 4. 绕圈飞行
- 鼠标保持在**左侧或右侧**
- 无人机会持续转圈飞行
- 适合观察特定区域

### 5. 悬停观察
- 按 **S键** 停止前进（抵消自动前进）
- 用鼠标调整观察角度
- 用 Space/Shift 调整高度

## ⚙️ 参数配置

### 当前默认配置

```javascript
飞行速度: 3.0          // 基础飞行速度
鼠标灵敏度: 0.3        // 鼠标控制灵敏度
旋转平滑度: 0.1        // 旋转平滑系数（越小越平滑）
视角速度: 0.05         // 视角旋转速度
飞行高度: 50           // 初始飞行高度
最小高度: 10           // 最低飞行高度
最大俯仰角: 60°        // 最大抬头/低头角度
自动前进: 启用         // 默认自动向前飞
```

### 控制台调整参数

```javascript
// 调整鼠标灵敏度（更灵敏）
this.firstPersonController.setMouseSensitivity(0.5)

// 调整鼠标灵敏度（更迟钝，更精确）
this.firstPersonController.setMouseSensitivity(0.1)

// 调整旋转平滑度（更快响应）
this.firstPersonController.setRotationSmoothing(0.2)

// 调整旋转平滑度（更平滑）
this.firstPersonController.setRotationSmoothing(0.05)

// 调整飞行速度
this.firstPersonController.setMoveSpeed(5.0)  // 更快
this.firstPersonController.setMoveSpeed(1.0)  // 更慢

// 切换自动前进
this.firstPersonController.toggleAutoForward()

// 调整飞行高度
this.firstPersonController.setHeight(100)

// 传送到指定位置
this.firstPersonController.setPosition(100, 50, 100)
```

## 🐛 常见问题

### Q1: 无人机飞得太快？
**A:** 
```javascript
// 降低飞行速度
this.firstPersonController.setMoveSpeed(1.5)

// 降低鼠标灵敏度
this.firstPersonController.setMouseSensitivity(0.1)
```

### Q2: 控制太灵敏，不好操作？
**A:** 
```javascript
// 降低鼠标灵敏度
this.firstPersonController.setMouseSensitivity(0.15)

// 增加平滑度
this.firstPersonController.setRotationSmoothing(0.05)
```

### Q3: 控制太迟钝？
**A:** 
```javascript
// 提高鼠标灵敏度
this.firstPersonController.setMouseSensitivity(0.5)

// 降低平滑度（更快响应）
this.firstPersonController.setRotationSmoothing(0.2)
```

### Q4: 想悬停不动怎么办？
**A:** 
```javascript
// 方法1：按S键停止前进
// 方法2：关闭自动前进
this.firstPersonController.toggleAutoForward()
```

### Q5: 不想自动前进？
**A:** 
```javascript
// 切换自动前进
this.firstPersonController.toggleAutoForward()
// 再次调用可重新启用
```

### Q6: 飞太低了看不清？
**A:** 
- 按住 **Space** 键上升
- 或调整初始高度：
```javascript
this.firstPersonController.setHeight(100)
```

### Q7: 如何回到起点？
**A:** 
```javascript
this.firstPersonController.reset()
```

### Q8: 鼠标移动没反应？
**A:** 
- 确保鼠标在3D画面区域内
- 确认已进入无人机模式（按钮显示"退出无人机模式"）
- 检查浏览器控制台是否有错误

## 📊 技术原理

### 鼠标位置映射
1. 获取鼠标在画布中的位置
2. 归一化到 -1 ~ +1 范围
3. 应用灵敏度系数
4. 限制最大角度

### 平滑插值
使用线性插值(Lerp)实现平滑过渡：
```javascript
currentRotation += (targetRotation - currentRotation) * smoothing
```

### 相机旋转
- **偏航(Yaw)**：绕Y轴旋转，控制左右
- **俯仰(Pitch)**：绕X轴旋转，控制上下
- **横滚(Roll)**：可选，暂未实现

## 🎨 高级技巧

### 1. 电影般的镜头运动

**环绕拍摄**：
- 鼠标固定在左侧或右侧
- 无人机会持续转圈
- 适合拍摄建筑全景

**跟踪拍摄**：
- 保持目标在画面中心
- 用鼠标微调方向
- 配合前进速度

**推拉镜头**：
- W键：推进镜头
- S键：拉远镜头
- 鼠标保持中心

### 2. 精确定位

**快速定位到高空俯视**：
```javascript
// 先调高度
this.firstPersonController.setPosition(0, 150, 0)
// 再调整观察角度（移动鼠标向下）
```

**巡视特定区域**：
```javascript
// 传送到目标区域
this.firstPersonController.setPosition(100, 50, 100)
// 调整飞行速度
this.firstPersonController.setMoveSpeed(2.0)
```
