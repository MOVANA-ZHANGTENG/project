# 第一人称控制使用说明

## 🎮 功能概述

第一人称控制系统允许您像在游戏中一样，以第一视角在3D场景中自由行走和观察。

## 🚀 快速开始

### 1. 进入第一人称模式

**方式一**：点击右上角调试控制面板的「**进入第一人称**」按钮

**方式二**：在控制台执行
```javascript
this.toggleFirstPersonMode()
```

### 2. 锁定鼠标（重要！）

进入第一人称模式后，**点击3D画面任意位置**锁定鼠标，此时鼠标将隐藏，可以自由旋转视角。

### 3. 开始探索

使用键盘和鼠标控制在场景中移动和观察。

### 4. 退出模式

- 按 **ESC** 键解锁鼠标
- 点击「**退出第一人称**」按钮返回轨道控制模式

## 🎯 操作方法

### 键盘控制

| 按键 | 功能 | 说明 |
|------|------|------|
| **W** 或 **↑** | 向前移动 | 相对于当前视角方向 |
| **S** 或 **↓** | 向后移动 | 相对于当前视角方向 |
| **A** 或 **←** | 向左移动 | 横向平移 |
| **D** 或 **→** | 向右移动 | 横向平移 |
| **Space** | 上升 | 垂直向上移动 |
| **Shift** | 下降 | 垂直向下移动 |
| **ESC** | 解锁鼠标 | 退出鼠标锁定状态 |

### 鼠标控制

| 操作 | 功能 |
|------|------|
| **左键点击画面** | 锁定/解锁鼠标 |
| **移动鼠标** | 旋转视角（需先锁定） |
| **左右移动** | 水平旋转视角（360°） |
| **上下移动** | 俯仰旋转视角（-90° ~ 90°） |

## 💡 使用技巧

### 1. 移动技巧

**组合键位**：
- **W + A**：向左前方移动
- **W + D**：向右前方移动
- **W + Space**：向前上方移动
- **S + Shift**：向后下方移动

**快速探索**：
- 按住 **W** 持续前进
- 配合鼠标调整方向
- 使用 **Space** 和 **Shift** 快速上下移动

### 2. 视角技巧

**查看上方**：
- 鼠标向上移动，可以看到天花板、上层货架

**查看下方**：
- 鼠标向下移动，可以看到地板、下层设备

**环顾四周**：
- 鼠标左右移动实现360°环视

### 3. 探索建议

**推荐探索路线**：
1. 从中心区域开始
2. 使用 **W** 向前移动
3. 遇到货架或设备时，用 **A/D** 横向移动绕过
4. 使用 **Space** 上升到不同高度观察

**推荐观察点**：
- 货架之间的通道
- 堆垛机工作区域
- 仓库顶部俯视
- RGV轨道沿线

## ⚙️ 参数配置

### 当前默认配置

```javascript
moveSpeed: 2.0        // 移动速度
lookSpeed: 0.002      // 视角旋转速度
height: 15            // 人物视角高度（眼睛位置）
minHeight: 5          // 最小高度限制
```

### 自定义配置

在控制台中调整参数：

```javascript
// 调整移动速度（更快）
this.firstPersonController.setMoveSpeed(5.0)

// 调整移动速度（更慢，更精确）
this.firstPersonController.setMoveSpeed(1.0)

// 调整视角旋转速度
this.firstPersonController.setLookSpeed(0.005)

// 调整人物高度
this.firstPersonController.setHeight(20)

// 设置初始位置
this.firstPersonController.setPosition(100, 15, 100)
```

## 🐛 常见问题

### Q1: 点击画面后鼠标没有锁定？
**A:** 
- 确保已进入第一人称模式
- 某些浏览器需要用户手势才能锁定鼠标
- 尝试刷新页面重试

### Q2: 移动没有反应？
**A:** 
- 检查是否已进入第一人称模式（按钮显示"退出第一人称"）
- 确认键盘焦点在浏览器窗口上
- 查看控制台是否有错误信息

### Q3: 视角旋转太快或太慢？
**A:** 
```javascript
// 旋转太快，降低速度
this.firstPersonController.setLookSpeed(0.001)

// 旋转太慢，提高速度
this.firstPersonController.setLookSpeed(0.005)
```

### Q4: 移动速度不合适？
**A:** 
```javascript
// 移动太快
this.firstPersonController.setMoveSpeed(1.0)

// 移动太慢
this.firstPersonController.setMoveSpeed(5.0)
```

### Q5: 如何退出鼠标锁定？
**A:** 按 **ESC** 键即可退出鼠标锁定状态

### Q6: 穿过了墙体或货架？
**A:** 当前版本暂未实现碰撞检测，移动时请注意避开障碍物。未来版本将添加碰撞检测功能。

### Q7: 相机高度太高或太低？
**A:** 
```javascript
// 调整到合适高度（单位：场景单位）
this.firstPersonController.setHeight(10)  // 降低高度
this.firstPersonController.setHeight(20)  // 提高高度
```

### Q8: 如何在特定位置开始？
**A:** 
```javascript
// 设置到指定位置（x, y, z）
this.firstPersonController.setPosition(100, 15, 100)
```

## 📊 性能提示

### 性能影响

第一人称控制系统对性能的影响很小：
- ✅ 每帧只更新相机位置和旋转
- ✅ 键盘事件监听效率高
- ✅ 不会增加额外的渲染负担

### 优化建议

对于低端设备：
- 降低移动速度可以减少视角切换频率
- 关闭阻尼效果（轨道控制器）以提升性能

## 🎨 两种控制模式对比

| 特性 | 轨道控制模式 | 第一人称模式 |
|------|------------|------------|
| **视角** | 第三人称，围绕场景旋转 | 第一人称，场景内部视角 |
| **控制** | 鼠标拖拽 | WASD + 鼠标 |
| **适用场景** | 全局观察、设计审查 | 沉浸式体验、巡视 |
| **优点** | 全局视野、操作简单 | 真实感强、沉浸感好 |
| **缺点** | 缺乏沉浸感 | 视野受限 |

**推荐使用方式**：
- 初始观察：使用**轨道控制模式**获取全局视野
- 细节检查：切换到**第一人称模式**深入探索
- 客户演示：两种模式结合使用，展示完整效果

## 🎓 学习建议

### 新手入门

1. **先熟悉轨道控制**：用鼠标拖拽熟悉场景布局
2. **切换到第一人称**：点击按钮进入第一人称模式
