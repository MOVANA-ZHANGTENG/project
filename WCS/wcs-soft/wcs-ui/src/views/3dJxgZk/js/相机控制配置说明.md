# 相机控制配置说明

## 📐 旋转角度限制

已为3D场景添加相机旋转角度限制，防止视角旋转到模型底部。

## ⚙️ 当前配置

### 垂直旋转限制（Polar Angle）
```javascript
minPolarAngle = Math.PI / 6      // 30度（最俯视角度）
maxPolarAngle = Math.PI / 2.2    // 约82度（最仰视角度）
```

**角度说明**：
- `0度` = 正上方俯视（天顶）
- `30度` = 当前最小角度，适度俯视
- `82度` = 当前最大角度，接近水平但看不到底部
- `90度` = 完全水平
- `180度` = 正下方仰视（天底）❌ 已禁止

### 可视化说明
```
        正上方 (0°) ❌禁止
            │
         30° ├─── 最小角度（可以俯视）
            │
         45° │
            │
         82° ├─── 最大角度（接近水平）
            │
         90° │   水平视角
            │
        180° │   正下方 ❌禁止
```

## 🎮 其他控制器配置

### 1. 阻尼效果（Damping）
```javascript
enableDamping = true         // 启用惯性效果
dampingFactor = 0.05         // 阻尼系数（越小越平滑）
```
**效果**：鼠标松开后相机会平滑减速停止，更加流畅自然

### 2. 缩放限制
```javascript
minDistance = 100            // 最近距离（防止穿模）
maxDistance = 2000           // 最远距离（防止看不清）
```

### 3. 平移配置
```javascript
enablePan = true             // 启用平移（鼠标中键拖拽）
panSpeed = 1.0               // 平移速度
```

### 4. 旋转速度
```javascript
rotateSpeed = 0.5            // 旋转速度（0.5 = 慢速）
```

### 5. 鼠标按键功能
```javascript
LEFT: 无功能               // 左键不操作
MIDDLE: DOLLY              // 中键缩放
RIGHT: ROTATE              // 右键旋转
```

## 🔧 自定义调整

### 调整旋转角度范围

如果您需要不同的角度限制，可以在 `TEngine.js` 第67-68行修改：

#### 更严格的限制（完全看不到底部）
```javascript
orbitControls.minPolarAngle = Math.PI / 4;    // 45度
orbitControls.maxPolarAngle = Math.PI / 2.5;  // 72度
```

#### 更宽松的限制（可以看到一点底部）
```javascript
orbitControls.minPolarAngle = Math.PI / 8;    // 22.5度
orbitControls.maxPolarAngle = Math.PI / 2;    // 90度
```

#### 只限制不看底部
```javascript
orbitControls.minPolarAngle = 0;              // 不限制俯视
orbitControls.maxPolarAngle = Math.PI / 2;    // 最多到水平
```

#### 固定俯视角度（不允许旋转）
```javascript
orbitControls.minPolarAngle = Math.PI / 4;    // 45度
orbitControls.maxPolarAngle = Math.PI / 4;    // 45度（相同=锁定）
```

### 限制水平旋转

如果需要限制左右旋转范围，取消注释第71-72行：

```javascript
// 只允许在前方180度内旋转
orbitControls.minAzimuthAngle = -Math.PI / 2;  // 左边90度
orbitControls.maxAzimuthAngle = Math.PI / 2;   // 右边90度

// 只允许正面观看
orbitControls.minAzimuthAngle = -Math.PI / 4;  // 左边45度
orbitControls.maxAzimuthAngle = Math.PI / 4;   // 右边45度

// 完全禁止水平旋转
orbitControls.minAzimuthAngle = 0;
orbitControls.maxAzimuthAngle = 0;
```

### 调整阻尼效果

```javascript
// 更快的响应（减少惯性）
orbitControls.dampingFactor = 0.1;

// 更慢的响应（增加惯性，更平滑）
orbitControls.dampingFactor = 0.02;

// 禁用阻尼（立即停止）
orbitControls.enableDamping = false;
```

### 调整旋转速度

```javascript
// 快速旋转
orbitControls.rotateSpeed = 1.0;

// 慢速旋转（更精确）
orbitControls.rotateSpeed = 0.3;

// 超快旋转
orbitControls.rotateSpeed = 2.0;
```

| 角度 | 弧度值 | 说明 | 推荐用途 |

| 0° | 0 | 正上方俯视 | 平面图、地图视角 |

## 🐛 常见问题

### Q1: 为什么设置后还是能看到底部？
**A:** 检查 `maxPolarAngle` 是否小于 `Math.PI/2`（90度）

### Q2: 相机旋转有延迟？
**A:** 这是阻尼效果，可以通过 `dampingFactor` 调整或设置 `enableDamping = false` 禁用

### Q3: 如何完全禁止旋转？
**A:** 设置 `orbitControls.enableRotate = false`

### Q4: 如何限制在某个固定角度？
**A:** 将 `minPolarAngle` 和 `maxPolarAngle` 设为相同值

### Q5: 阻尼不生效？
**A:** 确保在动画循环中调用了 `orbitControls.update()`（第89行）
