## 📋 当前键位配置

### 键盘控制（已确认正确配置）

| 按键 | 功能 | 说明 |
|------|------|------|
| **↑** 或 **W** | 前进 | 相对于当前视角方向向前 |
| **↓** 或 **S** | 后退 | 相对于当前视角方向向后 |
| **←** 或 **A** | 向左平移 | 横向左移（不转向） |
| **→** 或 **D** | 向右平移 | 横向右移（不转向） |
| **Space** | 上升 | 垂直向上移动 |
| **Shift** | 下降 | 垂直向下移动 |

## 🔧 手动测试脚本

在控制台执行：

```javascript
console.log('========== 方向键测试 ==========')

// 1. 检查控制器状态
console.log('1. 控制器启用:', this.firstPersonController.enabled)
console.log('2. 移动速度:', this.firstPersonController.moveSpeed)
console.log('3. 自动前进:', this.firstPersonController.autoForward)

// 2. 手动设置移动状态
console.log('\n设置前进状态...')
this.firstPersonController.moveState.forward = true

// 3. 等待3秒后检查位置
const startPos = this.ThreeEngine.camera.position.clone()
console.log('起始位置:', startPos)

setTimeout(() => {
  const endPos = this.ThreeEngine.camera.position.clone()
  const distance = startPos.distanceTo(endPos)
  console.log('结束位置:', endPos)
  console.log('移动距离:', distance.toFixed(2))
  
  if (distance > 1) {
    console.log('✅ 移动成功！说明update正常')
    console.log('问题可能在：键盘事件监听')
  } else {
    console.log('❌ 没有移动！说明update有问题')
    console.log('问题可能在：update逻辑或相机位置被重置')
  }
  
  // 重置状态
  this.firstPersonController.moveState.forward = false
}, 3000)

console.log('请等待3秒...')
```
