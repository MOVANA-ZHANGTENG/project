## 1. 概述

本文档描述了 RMS 与 AGV 的集成方法，包括接口协议、消息格式和相关示例等。

### 1.1 简介

- **通信协议**: TCP Socket，长连接，心跳机制
- **通信模式**: AGV作为客户端，RMS作为服务端
- **交互方式**: TCP request/response 问答模式
- **消息格式**: JSON
- **坐标系**: 世界坐标系（0°为东、90°为北、180°/-180°为西、-90°为南）

### 1.2 定义/缩略语

| 序号 | 英文简称 | 归类 | 英文全称 | 中文含义 |
|------|----------|------|----------|----------|
| 1 | RMS | 服务器 | Robot Management System | 机器人调度系统 |
| 2 | AGV | 客户端 | Automatic Guided Vehicle | 机器人 |

**数据流向说明**：
- 数据下行：RMS → AGV
- 数据上行：AGV → RMS

### 1.3 协议使用说明

#### 必达机制
- 采用请求/响应机制
- 接收方收到后需回复确认消息（ACK）
- 未收到确认则重发
- 重发机制：500ms 定时

#### 任务管理
- **阶段反馈**: 必须保证最后一次任务结束确认
- **任务队列**: 机器人维护指令队列，支持多任务并行执行
- **连贯性**: 保证机器人运行过程不停顿

#### 连接保持
- **超时时间**: RMS检测20秒无消息则断开连接
- **心跳机制**: 
  - 客户端写空闲20秒后发送心跳
  - RMS写空闲3秒后发送心跳
  - 心跳消息无需回复

#### 异常处理
- 收到不符合协议头部的错误数据包，不回复任何信息
- 其他情况下，机器人不会主动断开连接

## 2. 通信协议格式

### 2.1 通信类型

| 类型 | msgType 值 | 功能描述 | 发送方向 |
|------|------------|----------|----------|
| 指令通信 | InstructionRequestMsg | 任务调度指令、控制指令、数据同步等 | RMS → AGV |
| 指令应答 | InstructionResponseMsg | 指令确认应答 | AGV → RMS |
| 事件上报 | EventRequestMsg | 任务阶段变化事件 | AGV → RMS |
| 事件应答 | EventResponseMsg | 事件确认应答 | RMS → AGV |
| 心跳消息 | PingRequestMsg | 保持长连接 | RMS → AGV |
| 状态上报 | StateRequestMsg | 实时状态数据 | AGV → RMS |

### 2.2 请求消息格式

```json
{
  "msgType": "xxx",
  "robotId": 500001,
  "request": {
    "header": {
      "requestId": 112233,
      "version": "2.0.0",
      "extParam": "xxx"
    },
    "body": {
      "XXX": "xxx"
    }
  }
}
```

#### 请求消息字段说明

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| msgType | String | 是 | 消息类型（见通信类型表） |
| robotId | int | 是 | 机器人编号 |
| request | Object | 是 | 请求消息对象 |
| request.header | Object | 是 | 消息头 |
| request.header.requestId | long | 是 | 消息唯一标识（推荐自增） |
| request.header.version | String | 是 | 协议版本（固定值 2.0.0） |
| request.header.extParam | String | 否 | 透传字段 |
| request.body | Object | 是 | 消息正文 |

### 2.3 响应消息格式

```json
{
  "msgType": "EventResponseMsg",
  "robotId": 500001,
  "response": {
    "header": {
      "responseId": 112233,
      "code": 0,
      "msg": "success",
      "extParam": "xxx"
    },
    "body": {}
  }
}
```

#### 响应消息字段说明

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| msgType | String | 是 | 消息类型 |
| robotId | int | 是 | 机器人编号 |
| response | Object | 是 | 响应消息对象 |
| response.header | Object | 是 | 响应头 |
| response.header.responseId | long | 是 | 对应请求的requestId |
| response.header.code | int | 是 | 结果码（0正常，非0异常） |
| response.header.msg | String | 是 | 结果说明 |
| response.header.extParam | String | 否 | 透传字段 |
| response.body | Object | 否 | 响应正文（部分消息无） |

### 2.4 回车换行定义

⚠️ **重要**: 
- 使用回车符加换行符 `\r\n` 分割数据包
- 每条消息末尾必须添加 `\r\n`
- 消息体中不能包含回车换行符

### 2.5 自定义数据结构

#### 2.5.1 Point - 坐标

```json
{
  "x": 55500,
  "y": 25500,
  "z": 1,
  "moveMode": 1,
  "pointType": 1
}
```

| 字段 | 类型 | 必须 | 说明 | 示例 |
|------|------|------|------|------|
| x | int32 | 是 | X坐标，单位：微米（0.001米） | 55500 |
| y | int32 | 是 | Y坐标，单位：微米（0.001米） | 25500 |
| z | int32 | 是 | Z坐标（楼层），支持负数 | 1 |
| moveMode | int32 | 否 | 移动方式：1前进/2后退/3左侧移/4右侧移 | 1 |
| pointType | int32 | 否 | 路径点类型：1直线/2圆弧/3贝塞尔 | 1 |

#### 2.5.2 Component - 机构组件

```json
{
  "id": 1,
  "loadState": 1,
  "code": "0000001",
  "actualAngle": 0,
  "deltaAngle": 90
}
```

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| id | int32 | 是 | 组件编号（从1开始） |
| loadState | int32 | 否 | 负载状态：1空载/2负载 |
| code | String(16) | 否 | 货物编号 |
| actualAngle | int32 | 否 | 实际角度（单位0.01度） |
| deltaAngle | int32 | 否 | 角度变化量（单位0.01度） |

#### 2.5.3 StatusSum - 统计数据

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| mileage | int | 是 | 总里程(m) |
| liftNumber | int | 是 | 托盘上升总次数 |
| dorpNumber | int | 是 | 托盘下降总次数 |
| reversingX | int | 是 | X横向换向总次数 |
| reversingY | int | 是 | Y纵向换向总次数 |

#### 2.5.4 StatusTime - 当次统计数据

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| mileage | int | 是 | 当次里程(m) |
| liftNumber | int | 是 | 托盘上升本次次数 |
| dorpNumber | int | 是 | 托盘下降本次次数 |
| reversingX | int | 是 | X横向本次换向次数 |
| reversingY | int | 是 | Y纵向本次换向次数 |

#### 2.5.5 LastTaskData - 最后任务信息

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| x | int32 | 是 | 任务终点X坐标 |
| y | int32 | 是 | 任务终点Y坐标 |
| z | int32 | 是 | 任务终点Z坐标 |
| taskId | long | 是 | 任务ID（无任务时为0） |

## 3. 机器人通信指令协议（下行）

### 3.1 调度指令

**msgType**: `InstructionRequestMsg`

#### 3.1.1 移动指令（GO）

控制机器人按路径移动到目标点。

**body 字段**：

| 字段 | 类型 | 必须 | 说明 | 示例 |
|------|------|------|------|------|
| operationType | String | 是 | 固定值：COMMAND | "COMMAND" |
| operationCode | String | 是 | 固定值：GO | "GO" |
| taskId | long | 是 | 任务唯一ID | 1122223 |
| path | List<Point> | 是 | 路径点列表 | [{x,y,z,cellCode}] |
| follow | int | 否 | 是否跟随：0不跟随/1跟随 | 0 |
| endAngle | double | 否 | 终点角度（单位0.01度） | 9000 |
| adjustType | int | 否 | 末端校准类型：0-6 | 0 |
| isAllowEnterElevator | boolean | 否 | 是否允许进电梯 | true |

**示例**：

```json
{
  "msgType": "InstructionRequestMsg",
  "robotId": 500001,
  "request": {
    "header": {
      "requestId": 112233,
      "version": "2.0.0",
      "extParam": "1556"
    },
    "body": {
      "operationType": "COMMAND",
      "operationCode": "GO",
      "taskId": 1122223,
      "path": [
        {"x": 11002, "y": 12567, "z": 1, "cellCode": "10002000"},
        {"x": 11002, "y": 13567, "z": 1, "cellCode": "10002001"},
        {"x": 11002, "y": 14567, "z": 1, "cellCode": "10002002"}
      ]
    }
  }
}
```

#### 3.1.2 举升/放下指令

**operationCode**：
- 举升：`GO_LIFT_UP`
- 放下：`GO_LIFT_DOWN`

**body 字段**：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| operationType | String | 是 | 固定值：COMMAND |
| operationCode | String | 是 | GO_LIFT_UP / GO_LIFT_DOWN |
| taskId | long | 是 | 任务ID |
| path | List<Point> | 否 | 路径（可选） |
| shelfCode | String | 否 | 货架编号 |
| follow | int | 否 | 是否跟随 |
| endAngle | double | 否 | 终点角度 |
| adjustType | int | 否 | 末端校准 |
| calibration | boolean | 否 | 是否校准托盘（特殊车型） |

**举升示例**：

```json
{
  "msgType": "InstructionRequestMsg",
  "robotId": 500001,
  "request": {
    "header": {
      "requestId": 112234,
      "version": "2.0.0"
    },
    "body": {
      "operationType": "COMMAND",
      "operationCode": "GO_LIFT_UP",
      "taskId": 1122224
    }
  }
}
```

#### 3.1.3 去充电指令（GO_CHARGE）

**body 字段**：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| operationType | String | 是 | 固定值：COMMAND |
| operationCode | String | 是 | 固定值：GO_CHARGE |
| taskId | long | 是 | 任务ID |
| chargerId | String | 是 | 充电站编号 |
| chargerAngle | int | 是 | 插头朝向（单位0.01度） |
| path | List<Point> | 是 | 充电路径 |

**示例**：

```json
{
  "msgType": "InstructionRequestMsg",
  "robotId": 500001,
  "request": {
    "header": {
      "requestId": 112236,
      "version": "2.0.0"
    },
    "body": {
      "operationType": "COMMAND",
      "operationCode": "GO_CHARGE",
      "taskId": 1122226,
      "path": [
        {"x": 11002, "y": 12567, "z": 1},
        {"x": 11002, "y": 13567, "z": 1}
      ],
      "chargerId": "2",
      "chargerAngle": 9000
    }
  }
}
```

#### 3.1.4 开始/停止充电

**operationCode**：
- 开始充电：`START_CHARGE`
- 停止充电：`STOP_CHARGE`

**body 字段**：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| operationType | String | 是 | 固定值：COMMAND |
| operationCode | String | 是 | START_CHARGE / STOP_CHARGE |
| taskId | long | 是 | 任务ID |

#### 3.1.5 四向车更新楼层

**body 字段**：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| operationType | String | 是 | 固定值：DATA |
| operationCode | String | 是 | 固定值：UPDATE_FLOOR |
| location | Location | 是 | 楼层信息 |

**示例**：

```json
{
  "operationType": "DATA",
  "operationCode": "UPDATE_FLOOR",
  "location": {
    "x": 57701,
    "y": 47455,
    "z": 102
  }
}
```

### 3.2 控制指令

**msgType**: `InstructionRequestMsg`

#### 3.2.1 急停/恢复

**operationCode**：
- 急停：`STOP`
- 恢复：`RESUME`

**body 字段**：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| operationType | String | 是 | 固定值：CONTROL |
| operationCode | String | 是 | STOP / RESUME |

#### 3.2.2 限速/避障

**operationCode**：
- 限速：`LIMIT_SPEED`
- 宽度避障：`LIMIT_OBSTACLE_AROUND`
- 长度避障：`LIMIT_OBSTACLE_RANGE`

**body 字段**：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| operationType | String | 是 | 固定值：CONTROL |
| operationCode | String | 是 | 见上方操作码 |
| configPoints | List<ConfigPoint> | 是 | 控制路径点 |

**ConfigPoint 结构**：

```json
{
  "x": 1100,
  "y": 1200,
  "z": 1,
  "configValue": 1000
}
```

### 3.3 数据指令

**msgType**: `InstructionRequestMsg`

**operationCode 常量**：

| 指令类别 | 支持类型 | 说明 |
|----------|----------|------|
| MAP | 可选 | 下发地图数据 |
| RESTART_POINTS | 可选 | 下发重启点坐标 |
| LOCATION | 可选 | 下发机器人当前坐标 |
| SHELF_MODELS | 可选 | 下发货架模型 |
| BOX_MODELS | 可选 | 下发货箱模型 |

**Device数据同步示例**：

```json
{
  "msgType": "InstructionRequestMsg",
  "robotId": 500001,
  "request": {
    "header": {
      "requestId": 112236,
      "version": "2.0.0"
    },
    "body": {
      "operationType": "DATA",
      "operationCode": "LOCATION",
      "location": {
        "x": 11002,
        "y": 12567,
        "z": 1
      },
      "devicePoints": [
        {"x": 11002, "y": 12567, "z": 0},
        {"x": 11002, "y": 12567, "z": 0}
      ]
    }
  }
}
```

### 3.4 心跳

**msgType**: `PingRequestMsg`

⚠️ **无需应答**

**示例**：

```json
{
  "msgType": "PingRequestMsg",
  "robotId": 500001,
  "request": {
    "header": {
      "requestId": 112236,

    },

  }

```

⚠️ **无需应答**

**示例**：

```json
{
  "msgType": "EventResponseMsg",
  "robotId": 500001,
  "response": {
    "header": {
      "responseId": 12234567,
      "code": 0,
      "msg": "success"
    },
    "body": {}
  }
}
```

## 4. 机器人上行数据协议

### 4.1 事件上报

**msgType**: `EventRequestMsg`

#### 4.1.1 初始化请求（INIT）

机器人连接后上报当前位置。

**body 字段**：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| eventType | String | 是 | 固定值：INIT |
| qrCode | String | 是 | 节点编码 |

**示例**：

```json
{
  "msgType": "EventRequestMsg",
  "robotId": 500001,
  "request": {
    "header": {
      "requestId": 112236,
      "version": "2.0.0",
      "extParam": "1556"
    },
    "body": {
      "eventType": "INIT",
      "qrCode": "10001002"
    }
  }
}
```

#### 4.1.2 任务阶段上报（TASK_PHASE）

⚠️ **任务结束必须上报**

**body 字段**：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| eventType | String | 是 | 固定值：TASK_PHASE |
| taskId | long | 是 | 任务ID |
| taskState | int | 是 | 任务状态：0进行中/1完成/2异常 |
| pathState | int | 是 | 路径状态：0进行中/1完成 |
| statusCode | int | 是 | 状态码：0正常/非0异常 |
| mechanism | Component | 否 | 机构组件状态 |

**示例**：

```json
{
  "msgType": "EventRequestMsg",
  "robotId": 500001,
  "request": {
    "header": {
      "requestId": 112237,
      "version": "2.0.0"
    },
    "body": {
      "eventType": "TASK_PHASE",
      "taskId": 1122223,
      "taskState": 1,
      "pathState": 1,
      "statusCode": 0
    }
  }
}
```

### 4.2 遥测数据上报

**msgType**: `StateRequestMsg`

⚠️ **无需应答**

**上报频率**：
- 高频（50-100ms）：位置、角度、速度等调度相关字段
- 低频（1s）：电量、温度等

**body 字段**：

| 字段 | 类型 | 必须 | 说明 | 单位 |
|------|------|------|------|------|
| eventType | String | 是 | 固定值：STATE_DATA | - |
| robotTime | long | 是 | 时间戳（毫秒） | 0.001秒 |
| x | int | 是 | 当前X坐标 | 0.001米 |
| y | int | 是 | 当前Y坐标 | 0.001米 |
| angle | int | 是 | 方向角（-180~180） | 0.01度 |
| speed | int | 是 | 当前速度 | 0.001米/秒 |
| mechanism | List<Component> | 是 | 组件状态列表 | - |
| loadState | int | 是 | 负载状态：0空载/1负载 | - |
| shelfCode | String | 否 | 货架编码（负载时有效） | - |
| shelfAngle | int | 否 | 货架方位角度 | 0.01度 |
| pathState | int | 否 | 路径状态：0执行中/1完成 | - |
| taskState | int | 否 | 任务状态：0接收/1完成/2失败 | - |
| taskId | long | 否 | 当前任务ID | - |
| instructionCount | long | 否 | 接收到的任务流水号 | - |
| instructionType | String | 否 | 指令类别 | - |
| instructionCode | String | 否 | 指令编码 | - |
| powerPercent | int | 是 | 电池电量百分比（0-100） | % |
| batteryVoltage | int | 是 | 电池电压 | 0.001V |
| batteryElectric | int | 是 | 电池电流 | 0.001A |
| batteryTemperature | int | 是 | 电池温度 | 0.01℃ |
| chargingCurrent | int | 是 | 充电电流 | 0.001A |
| versionMap | List<int> | 否 | 软件版本列表 | - |
| ledState | int | 否 | 指示灯状态码 | - |
| workingMode | int | 是 | 手自动状态：0手动/1自动 | - |
| errorCodes | List<int> | 是 | 异常码集合 | - |
| statusSum | StatusSum | 是 | 总统计数据 | - |
| StatusTime | StatusTime | 是 | 当次统计数据 | - |
| idleAcceleration | int | 是 | 空载加速度 | 0.001米/秒² |
| loadAcceleration | int | 是 | 负载加速度 | 0.001米/秒² |
| idleMaxSpeed | int | 是 | 空载最大速度 | 0.001米/秒 |
| loadMaxSpeed | int | 是 | 负载最大速度 | 0.001米/秒 |
| loadWeight | int | 是 | 负载重量 | T |
| lastTaskData | LastTaskData | 是 | 最后任务信息 | - |

**示例**：

```json
{
  "msgType": "StateRequestMsg",
  "robotId": 500001,
  "request": {
    "header": {
      "requestId": 112238,
      "version": "2.0.0"
    },
    "body": {
      "eventType": "STATE_DATA",
      "robotTime": 1633024800000,
      "x": 11002,
      "y": 12567,
      "angle": 9000,
      "speed": 1000,
      "mechanism": [
        {
          "id": 1,
          "loadState": 1,
          "code": "SHELF001"
        }
```

## 5. 场景描述

### 5.1 运货架到某处放下场景

1. RMS 下发 `GO` 指令（移动到货架位置）
2. AGV 上报任务阶段（到达）
3. RMS 下发 `GO_LIFT_UP` 指令（举升货架）
4. AGV 上报任务阶段（举升完成）
5. RMS 下发 `GO` 指令（移动到目标位置）
6. AGV 上报任务阶段（到达）
7. RMS 下发 `GO_LIFT_DOWN` 指令（放下货架）
8. AGV 上报任务阶段（放下完成）

### 5.2 充电场景

1. RMS 下发 `GO_CHARGE` 指令（移动到充电站）
2. AGV 上报任务阶段（到达充电站）
3. RMS 下发 `START_CHARGE` 指令（开始充电）
4. AGV 定期上报状态数据（充电进度）
5. 充电完成后，RMS 下发 `STOP_CHARGE` 指令
6. AGV 上报任务完成

### 5.3 换路场景

1. AGV 执行移动任务中
2. RMS 下发新的 `GO` 指令（新路径）
3. AGV 取消当前任务，执行新路径
4. AGV 上报任务阶段变化

## 📌 注意事项

1. ⚠️ **消息分隔符**: 所有消息末尾必须添加 `\r\n`
2. ⚠️ **responseId**: 响应消息的 responseId 必须与请求的 requestId 一致
3. ⚠️ **requestId**: 推荐使用自增方式保证全局唯一
4. ⚠️ **任务结束**: 必须上报任务阶段
5. ⚠️ **坐标单位**: 统一使用微米（0.001米）
6. ⚠️ **角度单位**: 统一使用 0.01度
7. ⚠️ **空参数**: 不传参数时直接去掉该字段，不要传默认值（如空字符串、0等）
