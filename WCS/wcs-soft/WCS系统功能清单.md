## 详细功能说明

### 一、基础数据管理模块 (wcs-base)

#### 1.1 仓库管理
- **功能描述**：仓库基本信息维护、仓库模型配置、多仓库支持
- **主要功能**：
  - 仓库信息新增、修改、删除、查询
  - 根据编码查询仓库信息
  - 获取所有仓库选择框信息
  - 仓库模型配置
  - 仓库数据导出

#### 1.2 库区管理
- **功能描述**：库区信息维护、库区属性配置、库区划分
- **主要功能**：
  - 库区信息新增、修改、删除、查询
  - 库区编码和名称唯一性校验
  - 库区数据导出

#### 1.3 巷道管理
- **功能描述**：巷道信息维护、巷道属性配置、堆垛机巷道管理
- **主要功能**：
  - 巷道信息新增、修改、删除、查询
  - 巷道编码和名称唯一性校验
  - 巷道与仓库、库区关联管理
  - 巷道数据导出

#### 1.4 库位管理
- **功能描述**：库位信息维护、库位状态管理、批量创建库位
- **主要功能**：
  - 库位信息新增、修改、删除、查询
  - 批量创建库位（支持立体库和四向车）
  - 库位状态更新（包含托盘信息）
  - 根据巷道编码查询库位列表
  - 3D显示库位查询（包含托盘信息）
  - 库位配置更新（type、preCode、subX、subY、subZ等）
  - 库位数据导出

#### 1.5 托盘管理
- **功能描述**：托盘信息维护、托盘状态跟踪、RFID管理
- **主要功能**：
  - 托盘信息新增、修改、删除、查询
  - 托盘编码、RFID编码、名称唯一性校验
  - 托盘与库位关联管理
  - 托盘信息Excel导入导出
  - 托盘导入模板下载

#### 1.6 设备管理
- **功能描述**：设备信息维护、设备通信参数配置、设备状态管理
- **主要功能**：
  - 设备信息新增、修改、删除、查询
  - 设备编码唯一性校验
  - 设备通信参数配置（IP、端口、通信协议等）
  - 根据编码查询设备详情
  - 获取所有设备列表
  - 设备数据导出

#### 1.7 执行器管理
- **功能描述**：执行器配置、执行器分组、执行器类型管理
- **主要功能**：
  - 执行器信息新增、修改、删除、查询
  - 执行器编码唯一性校验
  - 根据类型获取执行器列表
  - 获取选中的执行器方法
  - 执行器数据导出

#### 1.8 任务类型管理
- **功能描述**：任务类型定义、任务流程模板配置、任务优先级设置
- **主要功能**：
  - 任务类型新增、修改、删除、查询
  - 任务类型编码和名称唯一性校验（按仓库）
  - 任务类型数据导出

#### 1.9 路径管理
- **功能描述**：执行路径维护、路径查询、路径历史记录
- **主要功能**：
  - 路径信息新增、修改、删除、查询
  - 根据作业ID查询路径列表
  - 根据历史作业ID查询路径列表
  - 路径数据导出

### 二、任务管理模块 (wcs-task)

#### 2.1 任务信息管理
- **功能描述**：任务创建、任务查询、任务修改、任务删除、任务状态跟踪
- **主要功能**：
  - 任务信息新增、修改、删除、查询
  - 任务列表查询（支持多条件筛选）
  - 获取所有任务列表
  - 任务详情查询
  - 任务起始库位和目标库位校验
  - 任务优先级自动设置
  - 任务数据导出
  - 任务统计（7天任务类型统计、任务基础统计）

#### 2.2 作业管理
- **功能描述**：作业步骤管理、作业执行、作业状态跟踪
- **主要功能**：
  - 作业信息新增、修改、删除、查询
  - 根据任务号查询作业列表
  - 根据任务ID查询作业列表
  - 根据历史任务号查询作业列表
  - 作业强制执行（cmd）
  - 作业强制完成（successPre）
  - 作业数据导出

#### 2.3 接口记录管理
- **功能描述**：WMS接口记录、接口调用查询、接口记录导出
- **主要功能**：
  - 接口记录新增、修改、删除、查询
  - 接口记录详情查询
  - 接口记录数据导出

#### 2.4 WMS接口对接
- **功能描述**：与WMS系统接口对接，接收WMS下发的任务
- **主要接口**：
  - 001 搬运任务（moveTask）：接收WMS下发的搬运任务
  - 002 作业取消（hostCancelTask）：接收WMS下发的作业取消指令
  - 006 目的地变更（changeTarget）：接收WMS下发的目的地变更指令
  - 008 拣选/盘点任务完成通知（taskCompletedNotice）：接收WMS下发的任务完成通知
  - 009 库存同步（InventorySync）：接收WMS下发的库存同步数据

## 技术特性

### 1. 系统架构
- **后端框架**：Spring Boot 2.5.15 + MyBatis
- **前端框架**：Vue.js 2.6.12 + Element UI（PC端） / UniApp + uView UI（移动端）
- **数据库**：MySQL（主数据库）+ SQL Server（与外部系统对接）
- **缓存**：Redis
- **安全框架**：Spring Security + JWT
- **任务调度**：Quartz
- **通信协议**：Modbus TCP、S7、Web Service等

### 2. 核心特性
- **模块化设计**：采用Maven多模块项目结构，便于维护和扩展
- **灵活配置**：支持灵活的参数配置，适应各种复杂场景
- **实时监控**：提供全面的实时监控功能，确保系统运行透明可控
- **智能调度**：采用先进的任务调度算法，提高作业效率
- **安全可靠**：采用JWT Token安全认证机制，完善的异常处理机制
- **易于扩展**：模块化设计使得系统易于扩展，可根据业务需求增加新功能

### 3. 数据管理
- **软删除支持**：支持软删除和硬删除两种模式
- **审计字段**：所有数据表包含创建时间、创建人、更新时间、更新人等审计字段
