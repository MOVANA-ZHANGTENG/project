# WCS平台功能架构图使用说明

## 📋 文件说明

**WCS平台功能架构图.html** - 科技感可视化架构图，尺寸1280x720（16:9比例），适合PPT截图

## 🎨 设计特点

- ✅ **科技感设计**：深色背景 + 霓虹色彩 + 发光效果
- ✅ **可视化效果**：渐变背景、动态光效、现代UI
- ✅ **PPT适配**：1280x720尺寸，16:9比例，完美适配PPT
- ✅ **清晰分层**：应用层 → 业务功能层 → 核心框架层 → 数据层 → 设备层

## 📸 截图步骤

### 方法一：浏览器全屏截图（推荐）

1. **打开文件**
   - 双击 `WCS平台功能架构图.html` 文件
   - 等待图表加载完成（约3-5秒）

2. **调整浏览器**
   - 按 `F11` 进入全屏模式（可选）
   - 按 `Ctrl + 0` 重置缩放为100%

3. **截图**
   - **Windows截图工具**：按 `Win + Shift + S`，选择区域截图
   - **QQ截图**：按 `Ctrl + Alt + A`
   - **微信截图**：按 `Alt + A`
   - **浏览器开发者工具**：按 `F12` → `Ctrl + Shift + P` → 输入 "screenshot"

4. **保存**
   - 保存为PNG格式（推荐，保持清晰度）
   - 或保存为JPG格式

### 方法二：使用截图软件

推荐使用以下专业截图工具：
- **Snipaste**（免费，功能强大）
- **FastStone Capture**（专业截图工具）
- **ShareX**（开源免费）

## 🎯 PPT使用建议

1. **插入图片**
   - 在PPT中插入截图
   - 建议使用PNG格式以保持清晰度

2. **调整大小**
   - PPT页面设置为16:9比例
   - 图片可以适当放大或缩小以适应页面

3. **添加说明**
   - 可以在图片下方添加文字说明
   - 建议使用白色或浅色字体（因为图片是深色背景）

## 💡 注意事项

1. **浏览器兼容性**
   - 推荐使用 Chrome、Edge、Firefox 最新版本
   - 需要网络连接（加载Mermaid.js库）

2. **显示问题**
   - 如果图表显示不完整，尝试调整浏览器缩放（Ctrl + 鼠标滚轮）
   - 确保浏览器窗口足够大以显示完整图表

3. **离线使用**
   - 如需离线使用，可以下载Mermaid.js库到本地并修改引用路径

4. **自定义修改**
   - 可以直接编辑HTML文件修改颜色、文字等内容
   - 修改后刷新浏览器即可看到效果
